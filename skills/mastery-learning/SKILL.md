# 掌握式自适应学习（Mastery Learning）

**一句话准则：先摸底、再教、学透才走、题按人出、难度自适应。目标不是"读过"，是"会干"。**

这套方法把"学习"从一次性投递文档，变成一个人机协作、逐阶段闭环、以真正掌握为推进条件的过程。与具体领域无关，可用于学习任何知识或技能。

## 一、何时使用

- 用户要系统学一门新知识 / 新技能，从零到能上手。
- 用户要设计一套课程、讲义、练习与测评。
- 用户说"讲透一点""我还没懂""学会了再往下""别赶进度"。
- 用户抱怨过往学习"课程太薄 / 题目超纲 / 学完还是不会用 / 一上来就太难放弃"。
- 用户要把"学习→掌握→落地"整条链交给 AI 陪跑。

## 二、五条硬规则（不可妥协）

1. **诊断前置**：任何学习开始前，先出一组摸底题探清学习者对该知识的真实底子，分三态——完全不会 / 了解不全 / 已经会。已会的跳过，了解不全的只补缺口，完全不会的从零讲透。**"没经验"不等于"一无所知"**：学习者往往对部分概念已有零散认知（如会算简单价格但不全），一律从零灌是浪费，还打击积极性。
2. **一步一步出**：一次只出一个阶段的讲义。前一阶段没真正掌握，绝不往下发。
3. **对话讲透**：每个阶段在对话里讲透，不是扔一份文档让学习者自学。学的过程中随时提问，当场讲到懂。
4. **学完再出题、题按人出**：正式测试卷不预先写死。学习者确认学完后，才根据其学习情况、问过的问题、卡过壳的地方现出题。可维护一份"备用题库"作题源，但正式卷必须现场按人生成。
5. **掌握式推进 + 自适应**：达到掌握标准才进下一阶段；没掌握就针对薄弱点重讲 + 补测。下一阶段的难度和侧重，根据本阶段的表现动态调整——学得轻松就加码，学得吃力就降难度、补前置。

## 三、教学原则（展开）

- **课程与测试分离**：讲义文档只讲知识，题库文档只攒题；两者不同文件。题只考本阶段刚讲过的内容，知识来源唯一且可追溯，答不出就是本阶段没掌握，不会是"没学后面"造成的。
- **掌握标准要明确且可判**：建议正确率 ≥ 80% 且关键应用题全对。不达标不算过。
- **难度自适应是双向的**：既防止太难导致放弃，也防止太简单导致敷衍。学得吃力→补前置、拆小步、多举例；学得轻松→加深、加压、提速。
- **学完要能落地**：课程不是终点。设计时就想清楚"学完能干什么"，并规划课程结束后的实操衔接（人机分工 + 分阶段落地路线）。

## 四、标准闭环（一个阶段的完整流程）

每个阶段都走这套循环，一步一步来：

0. **诊断前置**：出讲义前，先出摸底题探底，分三态。摸底结果决定这份讲义写什么、详略怎么安排。
1. **出讲义**：根据诊断结果，出本阶段讲义 → 学习者学。
2. **对话讲透**：学习中随时提问，当场讲到懂。
3. **学完再出题**：学习者确认学完 → 根据其学习情况 + 问题情况，现出测试题。
4. **批改**：逐题批改，判断是否完全掌握（正确率 + 关键应用题）。
5. **没掌握就巩固**：针对薄弱点重讲 + 补测，回到第 4 步，直到掌握。
6. **调难度进下一阶段**：根据本阶段表现调整下一阶段难度和侧重 → 出下一阶段讲义 → 回到第 0 步。

全部阶段走完 → 进入"实操衔接阶段"（见第七节）。

## 五、阶段划分原则

- 把目标知识拆成若干阶段，每阶段有清晰的"学完你能做什么"。
- 阶段粒度：一个阶段应能在一到两次对话里讲透并测完，不宜过大。
- 顺序：从底层认知 → 平台/环境 → 核心方法 → 操作执行 → 风控/复盘 → 落地衔接。具体按领域调整。
- 维护一份总纲，记录：教学原则、阶段框架、进度、文件索引、信源与诚实边界。

## 六、出题与诊断规则

- **摸底题（诊断用）**：覆盖本阶段核心知识点，题目要能区分三态。不追求全，追求能定位"哪些已会、哪些是缺口、哪些完全空白"。
- **测试题（判掌握用）**：只考本阶段。题型混合：填空、判断（要求写理由，防止蒙对）、应用/计算、简答（用自己的话复述）。关键应用题单独标注，全对才算掌握。
- **动态生成**：正式卷按学习者的薄弱点和提问现场生成，题库只作备用题源。
- **答案与批改分离**：参考答案供批改者用，学习者答题前不可见。

## 七、实操衔接（学完之后的落地）

课程结束后进入共同实操阶段，不再是学习，而是把知识用起来。明确两件事：

1. **人机分工**：AI 负责要算、要查、要写、要对比的部分；学习者负责要拍板、要沟通、要承担后果的部分。
2. **落地路线**：列出从 0 到第一个成果、再到持续产出的分步路线，每一步都先算账 / 先验证再动手，控制风险、不冒进。

## 八、反模式（明确禁止）

- 不做诊断就从零灌，浪费学习者已有认知。
- 一次性把所有阶段讲义全吐出来，不等掌握就往下推。
- 预先写死测试卷、题考了没学过的后续内容，导致无法判断问题出在哪。
- 讲义和测试混在一个文档，学习者答题时能看到答案。
- 只看正确率不看关键应用题，放过核心漏洞。
- 扔文档让学习者自学，不在对话里讲透。
- 难度一刀切，不随学习者表现调整。
- 课程学完就结束，不规划落地，导致"懂了但不会干"。

## 九、信源与诚实边界

- 课程知识标注来源与时效；关键结论注明出处。
- 平台/规则类以官方最新条款为准，二手话术不作为依据。
- 估算数字明确标"估算口径"，不当成实测数据。
- 不确定的内容直说不确定，不编造。
