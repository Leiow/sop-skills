# 掌握式自适应学习（mastery-learning）

把任意知识/技能拆成阶段化课程，带学习者真正学透而不是读完就算。与具体领域无关，可用于学习任何知识或技能。

完整规则见 [SKILL.md](SKILL.md)。

## 何时使用

- 系统学一门新知识/新技能，从零到能上手。
- 设计一套课程、讲义、练习与测评。
- 说"讲透一点""我还没懂""学会了再往下""别赶进度"。
- 抱怨过往学习"课程太薄/题目超纲/学完还是不会用/一上来就太难放弃"。

## 核心闭环

1. **诊断前置**：学之前先摸底，分三态——完全不会 / 了解不全 / 已经会。已会的跳过，了解不全的只补缺口，完全不会的从零讲。"没经验"不等于"一无所知"，一律从零灌是浪费。
2. **一步一步出**：一次一个阶段，前一阶段没真正掌握不往下发。
3. **对话讲透**：在对话里讲，不扔文档自学；随时提问，当场讲到懂。
4. **学完再出题**：测试题不预先写死，按个人学习情况、问过的问题、卡壳处现出；只考本阶段。可备题库作题源，正式卷按人生成。
5. **掌握式推进**：正确率 ≥ 80% 且关键应用题全对才过关；没过就针对薄弱点重讲 + 补测。
6. **难度自适应**：学得轻松加码提速，学得吃力降难度、补前置、拆小步。
7. **实操衔接**：学完规划从会到能干的分步落地路线，明确人机分工。

## 五条硬规则

1. 诊断前置，只补缺口。
2. 一次一个阶段，没掌握不往下。
3. 对话讲透，不扔文档。
4. 学完再出题、题按人出。
5. 掌握式推进 + 难度双向自适应。

## 反模式（禁止）

- 不诊断就从零灌。
- 一次吐出所有阶段讲义。
- 预先写死测试卷、题考了没学过的后续内容。
- 讲义和测试混一个文档，答题能看到答案。
- 只看正确率不看关键应用题。
- 扔文档自学，不在对话里讲透。
- 课程学完就结束，不规划落地。
