# sop-skill

一组可复用的 AI 协作技能（SKILL）。每个技能一个目录，遵循 `skills/<name>/SKILL.md` 结构，可直接放入支持 SKILL 规范的 AI 客户端使用。

## 技能列表

| 技能 | 目录 | 作用 |
|---|---|---|
| 掌握式自适应学习 | `skills/mastery-learning/` | 把任意知识/技能拆成阶段化课程，诊断前置、对话讲透、学完按个人情况出题、掌握式推进、难度自适应、学完衔接实操。适用于系统学习一门新知识、设计课程、陪跑式学习。 |

## 安装

把需要的技能目录复制到你的 AI 客户端技能目录即可，例如：

```bash
cp -r skills/mastery-learning ~/.workbuddy/skills/
```

不同客户端的技能目录位置不同，按各自规范放置 `SKILL.md`。

## 掌握式自适应学习 · 用法速览

触发：说"系统学习 X""从零掌握 X""讲透一点""帮我设计课程"等。

核心闭环：

1. **诊断前置**：学之前先摸底，分清完全不会 / 了解不全 / 已经会，只补缺口不从头灌。
2. **一步一步出**：一次一个阶段，前一阶段没掌握不往下发。
3. **对话讲透**：在对话里讲，不扔文档自学；随时提问当场讲透。
4. **学完再出题**：测试题按个人学习情况现出，不预先写死；只考本阶段。
5. **掌握式推进**：正确率 ≥ 80% 且关键应用题全对才过关，否则重讲 + 补测。
6. **难度自适应**：学得轻松加码，学得吃力降难度补前置。
7. **实操衔接**：学完规划从会到能干的分步落地路线。

完整规则见 `skills/mastery-learning/SKILL.md`。
